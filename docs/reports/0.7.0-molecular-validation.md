## Small repeated-input experiment

Four further requests repeated the full state and masked baseline twice each.
For `insufficient_evidence`, full scores were 0.61 and 0.63 (mean 0.62, sample SD
0.014142); baseline scores were both 1.00. Reported usage was 5,914 input and
1,072 output tokens. Observed request durations were 263–632 ms on this machine.
They are neither service latency guarantees nor complete billing totals.

This establishes that pinning Jev and fixing inputs does **not** make hosted
outputs deterministic. Archived replay reproduces the observed evaluations.
Permutation SE excludes this provider variation; small numerical residuals only
verify reconciliation within the archived game.

## Scientific status and dependencies

No cancer cohort or true CUP outcomes were evaluated. No sensitivity, specificity,
clinical calibration, treatment benefit or equivalence to OncoNPC is established.
The detailed cancer labels and abstention thresholds are experimental. Live
provider use retains the project's synthetic-only restriction.

Native SBS96/NNLS derivation is an experimental numerical method. Imported
projection scores and fitted exposures remain distinct. No COSMIC catalogue or
reference genome is bundled; compatibility and callable-territory assumptions
must be reviewed for the intended assay. Signature uncertainty and targeted-panel
identifiability have not been validated.

The cohort runner and local scoring tools are implemented. Representative
patient-disjoint development/calibration/test data, institution/panel/time
holdouts, modality ablations, background sensitivity and larger provider
repeatability experiments remain prerequisites for scientific conclusions.
Calibration fitting and bootstrap intervals are not installed. These open
scientific items do not prevent the synthetic engineering workflow from running.
